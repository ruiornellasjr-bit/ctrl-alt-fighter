# BBS ONE Academy

Versão estática da interface BBS ONE Academy, mantida na pasta `BBS Academy` do repositório CTRL+ALT+FIGHTER.

- Site público no ChatGPT: https://bbs-comece-por-aqui.bbsone-2952.chatgpt.site/
- Repositório compartilhado: https://github.com/ruiornellasjr-bit/ctrl-alt-fighter/tree/main/BBS%20Academy
- Publicação automática pelo GitHub Pages: https://ruiornellasjr-bit.github.io/ctrl-alt-fighter/
- Entrada: `index.html`
- Identidade visual: `assets/logo-bbs-one.png`

Esta pasta não participa do build do jogo (`pnpm build`). Alterações enviadas à pasta `BBS Academy` na branch `main` são publicadas automaticamente no GitHub Pages pelo workflow `.github/workflows/deploy-bbs-academy.yml`. O endereço do ChatGPT permanece disponível como publicação separada.

## Colaboração

Para contribuir, faça um fork do repositório e abra um pull request com as alterações. Quem tiver permissão de escrita também pode trabalhar em uma branch e abrir um pull request para `main`. Depois que a alteração for aprovada e integrada, a publicação do GitHub Pages é atualizada automaticamente.

A interface permite associar links de vídeo e apostilas às aulas, mas, enquanto não houver autenticação e armazenamento central aprovados, esses links e o progresso permanecem no navegador local. Os certificados disponíveis são modelos de apresentação, sem emissão ou validade oficial.
