# BBS ONE Academy

Versão estática da interface BBS ONE Academy, mantida como projeto separado dentro do repositório CTRL+ALT+FIGHTER.

- Site público atual: https://bbs-comece-por-aqui.bbsone-2952.chatgpt.site/
- Entrada: `index.html`
- Identidade visual: `assets/logo-bbs-one.png`

Esta pasta não participa do build do jogo (`pnpm build`) nem da publicação atual do CTRL+ALT+FIGHTER. A atualização do Site público no ChatGPT continua sendo feita pelo fluxo Sites.

A interface permite associar links de vídeo e apostilas às aulas, mas, enquanto não houver autenticação e armazenamento central aprovados, esses links e o progresso permanecem no navegador local. Os certificados disponíveis são modelos de apresentação, sem emissão ou validade oficial.
